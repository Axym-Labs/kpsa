# Cross-modal regularity experiment

- Setting: scientific premise test followed by a frozen downstream confirmation.
- Time budget: four hours for the first complete cross-modal result.
- Primary target: `src/task_embeddings/timeseries_parameter_circuits_v8.py`.
- Read-only files: the v8 specification and all existing frozen result JSONs.
- Premise: nearby forecasting contexts in a pretrained time-series representation
  have more similar normalized parameter-group sensitivity profiles than matched
  shuffled pairings or a context-independent scalar profile.
- Development metrics: held-out profile Spearman and direct-gradient top-group
  coverage, always accompanied by scalar, nearest, raw-context, latent-space,
  and matched-shuffle controls.
- Downstream metric: exact antithetic parameter-perturbation susceptibility for
  selected groups; higher paired gain over scalar and matched shuffle is better.
- Gate: advance only if a representation-conditioned method beats both scalar
  and matched shuffle on a held-out development split. Freeze representation,
  bandwidth, group resolution, and budgets before confirmation.
- Primary model: pretrained PatchTST forecasting model on ETTh1. If the premise
  passes, prefer a modern broadly pretrained checkpoint for confirmation when
  runtime permits. If it fails after bounded representation/bandwidth checks,
  switch to protein masked modeling with ESM-2 rather than tuning indefinitely.
- Reproducibility: record every tested configuration in
  `.codex/experiments/results.tsv`; do not modify or delete existing results.
- Repository note: this workspace is not a Git checkout, so isolation uses new
  files and new result paths rather than a branch/worktree.
